# Troubleshooting Reference: Common Everyday Computer Problems

Use this as a quick lookup for first checks. Always confirm the user's device and operating system before giving system-specific steps.

## Identifying the operating system
| What the user sees | Likely system |
| :--- | :--- |
| Four-square Windows logo at the bottom-left or bottom-center of the screen | Windows |
| Apple logo in the top-left corner; row of icons (the Dock) at the bottom | macOS (Mac) |
| Circle icon at bottom-left, mostly Google apps, laptop says "Chromebook" | ChromeOS |
| Apple phone or tablet; Settings app with a gray gear icon | iOS / iPadOS |
| Phone of another brand (Samsung, Google Pixel, Motorola, etc.) | Android |

## Common problems and first checks
| Category | How users often describe it | First checks (in order) |
| :--- | :--- | :--- |
| Internet / Wi-Fi | "Internet is down", "no bars", "page won't load" | Are other devices online? Is Wi-Fi turned on? Airplane mode off? Restart the router and modem (unplug 30 seconds, plug back in, wait 2-3 minutes) |
| Slow computer | "Super slow", "keeps freezing", "spinning circle" | Full restart; close extra programs and browser tabs; check free storage space; install pending updates |
| Printer | "Won't print", "says offline" | Printer on and showing no errors; paper and ink; printer and computer on the same Wi-Fi; clear stuck print jobs; restart printer, then computer |
| Email | "Can't send", "emails disappeared", "can't log in" | Internet working? Check Spam, Trash, and Archive folders; correct password; mailbox storage full |
| Passwords & accounts | "Locked out", "forgot password" | Use the official "Forgot password" link on the real website or app; check the recovery email or phone |
| Sound | "No sound", "they can't hear me" | Volume up and not muted; correct speaker or microphone selected; headphones unplugged/connected properly; app has microphone permission |
| Camera | "Camera not working" | Physical camera cover or switch; app has camera permission; close other apps using the camera; restart |
| Display | "Screen black", "everything is huge/tiny", "screen is sideways" | Power and cables; brightness; wake with a key or mouse move; display scaling/zoom; screen rotation |
| Lost files | "Lost my document", "can't find my download" | Recent files list in the program; Downloads folder; search; Recycle Bin (Windows) or Trash (Mac); cloud storage (OneDrive, iCloud, Google Drive) |
| Pop-ups & scams | "Virus warning with a phone number", "browser frozen saying call Microsoft" | Do NOT call; close the browser (force-close if needed); run the built-in security scan; don't install anything the pop-up suggests |
| Updates | "Keeps asking to update", "update stuck" | Plug into power; wait (large updates can take a long time); restart; check free storage |
| Mouse / keyboard / Bluetooth | "Mouse not working", "won't connect" | Batteries or charge; try another USB port; turn Bluetooth off and on; remove and re-pair the device |
| Phone storage full | "Can't take pictures, storage full" | Check storage in Settings; back up and remove old videos; clear large unused apps |

## Built-in security tools (prefer these over downloaded "cleaners")
| System | Built-in protection |
| :--- | :--- |
| Windows | Windows Security (search "Windows Security" from the Start menu) |
| Mac | Built-in protections run automatically; keep macOS updated |
| ChromeOS | Built-in protections; keep ChromeOS updated |
| iPhone / Android | Install apps only from the official app store; keep the phone updated |

## Escalation checklist
Recommend a repair shop, the manufacturer, the internet provider, or workplace IT when there is:
- Physical damage, liquid spills, burning smell, swollen battery, grinding or clicking noises
- A fix that requires opening the device
- Important files with no backup that need recovering
- A scam involving payment, banking info, or remote access (also: call the bank)
- A locked work or school device
- No progress after standard steps, and the remaining steps carry real risk

Menu names and locations change between versions. When a step doesn't match the user's screen, ask them what they see and adjust.
